# 🔐 Доступы этого проекта — через Хранителя

Секреты (ключи, токены, пароли, .env, service-account) под управлением
субагента-Хранителя. НЕ ищи и не правь их вручную.

За новым доступом / ключом / ротацией:
→ запусти субагента secret-keeper (Agent tool, subagent_type: "secret-keeper"),
  назови намерение: ПЕРЕНОС / ШИФРОВАНИЕ / ИСПОЛЬЗОВАНИЕ / РОТАЦИЯ.

Карта «где что лежит» (без значений):
C:\Users\User\.claude\agents\secret-keeper-memory\РЕЕСТР_секретов.md

Значения хранятся в шифре (sops+age), в открытом виде и в чат не выводятся.

## Известное ограничение среды

Живая сетевая проверка внешних API (Telegram/Google) из песочницы
инструмента Bash в Claude Code может не проходить из-за TLS-перехвата
прокси песочницы (self-signed certificate в цепочке). Это не проблема
конфигурации проекта — при необходимости проверяйте интеграции локальным
`npm run dev` у себя на машине.
