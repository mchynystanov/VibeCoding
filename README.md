# Paomma Shop

Одностраничный интернет-магазин (лендинг с корзиной) для товаров бренда
Paomma. Заявки уходят в Telegram и Google Sheets. Подробнее — см. `CLAUDE.md`
и `TODO.md`.

## Запуск с секретами (Telegram / Google Sheets)

`.env` в этом проекте хранится в зашифрованном виде (sops + age) — см.
`ХРАНИТЕЛЬ.md`. Открытые значения нигде на диске не лежат.

- `npm run dev` и `npm run start` **автоматически** запускаются через
  `scripts/with-secrets.mjs`, который:
  - если `.env` существует и не пуст — поднимает процесс через
    `sops exec-env .env -- next dev` (или `next start`), секреты попадают
    только в переменные окружения дочернего Next.js-процесса;
  - если `.env` отсутствует или пуст (например, при чистой вёрстке без
    интеграций) — запускает `next dev`/`next start` напрямую, без sops.
- `npm run build` секреты не использует и запускается как обычный
  `next build`. **Важно:** если в `.env` появятся значения
  `NEXT_PUBLIC_WHATSAPP_FALLBACK` / `NEXT_PUBLIC_TELEGRAM_FALLBACK` (они
  инлайнятся Next.js в клиентский бандл на этапе сборки, а не в рантайме) —
  для прод-сборки `build` тоже нужно будет обернуть через
  `sops exec-env .env -- next build`, иначе эти fallback-значения попадут в
  сборку пустыми. Сейчас эти переменные ещё не заполнены, поэтому не
  критично.

Ручная расшифровка/чтение `.env` не требуется и не нужна — расшифровкой
занимается сам `sops` внутри `scripts/with-secrets.mjs` на лету, значение
никогда не появляется на диске в открытом виде и не печатается в терминал.

За доступами и ротацией — см. `ХРАНИТЕЛЬ.md`.
